# 行业异质性归因审查结论 + 类型化因子方案（2026-09-01）

## 一、问题定性（用户质疑成立，但结论方向需精确表述）

用户：证劵/农业/银行/半导体等公司类型差异极大，分类细分程度不同，量化是否也该不同？是否存在严重归因错误？

**结论：方法论缺口成立，但「负结论」方向上是保守的（非误导），需按下述三处修正。**

## 二、三个具体的归因问题（数据已证实）

### 问题 1：因子在部分行业「无定义」，被静默排除
`equity_sector_het.py matrix`（2026H1 有值标的数/行业总数）：

| 行业 | revenue_yoy | gross_margin | net_margin | ocf_to_rev | asset_liab |
|---|---|---|---|---|---|
| Financials | 14/17 | **0/17** | 12/17 | 9/17 | 9/17 |
| Energy | 6/6 | **0/6** | 5/6 | 5/6 | 3/6 |
| Utilities | 5/6 | 1/6 | 4/6 | 2/6 | 5/6 |
| Healthcare | 10/12 | 7/12 | 8/12 | **1/12** | 8/12 |

- 银行/保险/券商/交易所**无销售成本** → gross_margin 无意义；能源/公用同理。
- 金融股**无「经营现金流」**（现金流表口径是存贷/保费变动）→ ocf_to_revenue 语义错。
- 结论：「110 只池」是假象，gross_margin 的有效池只有 ~55 只非金融，ocf 更少。每个因子在**不同的、非随机的隐性子池**上被检验。

### 问题 2：单一池化 IC 假设「因子→收益」跨类型同质，实证不成立
`equity_sector_het.py sector-ic`（各行业内期级 IC，符号不一致 = 异质）：

| 因子 | 正向行业 | 负向行业 |
|---|---|---|
| revenue_yoy | 材料 +0.28 / 通信 +0.23 / 地产 +0.30 | 能源 **-0.20** / IT -0.08 |
| net_margin_proxy | IT +0.215(t=1.96)/地产 +0.625 | 非金融整体 -0.03 |
| asset_liability | 工业 +0.667 / 金融 +0.18 | 地产 **-0.53** / 非金融 -0.076(t=-1.62) |

- 同一因子在不同行业**符号相反**（revenue_yoy 能源负、材料正；asset_liability 工业正、地产负）。
- 池化 IC 是这些异质效应的**加权平均**，既可能把真信号洗掉（Type II：漏掉行业条件 alpha），也可能把某个行业的伪信号摊薄成「看起来稳健」。
- **早期「revenue_yoy 负向 = 成长陷阱」的结论**，经拆分其实是**非金融/特定行业**的时段现象，金融股 revenue_yoy 反而 +0.11（正）。

### 问题 3：金融股的因子概念性失效（分类细分程度不一致的根源）
`Financials` 17 只内部高度异质：银行 9 / 保险 5 / 券商 2 / 交易所 1。给银行算 net_margin_proxy（净利润/营业收入）≈ 效率比而非毛利概念；asset_liability_ratio（杠杆 90%+）是资本结构而非「便宜度」信号——与非金融股的杠杆语义完全不同，跨行业不可比。

## 三、修正后的方法学（类型化量化）

1. **因子分类型定义**（不再一套因子打天下）：
   - 非金融工业/消费：gross_margin / ocf_to_revenue / inventory_to_revenue / rd_intensity / EV/EBITDA
   - 银行：ROE / 净息差(NIM) / 不良率 / 拨备覆盖率 / P/B / 存款增速
   - 保险：新业务价值(NBV)增速 / 内含价值 / 综合成本率 / P/EV
   - 券商：ROE / 经纪+投行+资管收入结构 / 资本杠杆 / P/B
   - 半导体/硬科技：资本开支强度 / 研发强度 / 库存周转 / 产能利用率 / PS
   - 地产：合约销售 / 净负债率 / 拿地强度 / 存货周转 / NAV 折价
   - 农业/资源：商品价格弹性 / 库存 / 产能 / 成本曲线

2. **主判定改「行业条件 IC」**：每行业独立算期内 IC，再检验跨行业同质性（符号一致 + 量级收敛）；不做单一池化 IC 当结论。**多重比较校正**：11 行业 × N 因子，行业级 t 需 ≥ ~3 才谈得上 alpha。

3. **金融/非金融分离建模**（Fama-French 传统做法）：金融股另案，不与工业股共用杠杆/毛利类因子。

4. **数据层**：金融类报表抽取需专门 prompt（取「归母净利润 / 净资产 / 总资产」而非毛利/经营现金流）；用 `equity_crosscheck.py` 的 E12（单位混合）持续扫描。

## 四、类型化因子落地后的实证结果（2026-09-01，`outputs/equity_type_factors_20260901.json`）

新增金融/质量通用因子（从现有 facts 直接算出，无需重新抽取）：
`roe`（净利/平均净资产）、`roa`（净利/平均总资产）、`equity_ratio`（权益/资产）、`net_profit_yoy`。
2026H1 覆盖 67/72/75/80 只——**金融股终于有了概念正确的因子**（此前 gross_margin/ocf 在金融为 0/17）。

**多重比较校正（MCC）**：11 行业 × 9 因子 = 99 格，Bonferroni 双尾阈值 **t ≥ 3.48**。

| 结论 | 结果 |
|---|---|
| 通过 MCC 且 n≥5 | **无** |
| 边缘（\|t\|≥1.96, n≥5，未过 MCC） | 净利润同比·医药 +2.96(n=6)<br>净利润同比·IT **-2.51**(n=10, IC>0 仅 20%)<br>gross_margin·IT -2.27(n=8)<br>net_margin·IT +1.96(n=12) |
| 显著但 n<5（一律判伪） | 工业净利润同比 t=+**8.00**(n=3)、工业 asset_liability +5.00(n=3)、工业 roa/equity_ratio -5.00(n=3) 等 7 项 |

- **工业股 t=8.00 是教科书级小样本伪信号**（n=3；同期 roa/equity_ratio 又反向 t=-5.00，自相矛盾）→ 与本项目「凡 n 太小的『显著』一律判伪」纪律一致。
- **IT 行业三个边缘信号符号自相矛盾**：gross_margin 负、net_margin_proxy 正、net_profit_yoy 负 → 判为噪声而非 alpha。
- 金融股内部：roe 行业内 t=-0.07（≈0）、roa +0.89、权益比率 -1.15 → **金融股概念正确的因子同样无信号**。

## 五、对既有「负结论」的影响

- **不推翻，但需重新表述**：原「简单公开因子无稳定 alpha」在**池化口径下仍成立**（保守），但它**不能排除行业条件 alpha**，且金融股因子的 IC 数字是噪声非信号。
- 类型化因子落地后（金融股有了 ROE/ROA/权益比率），**行业内条件 IC 经 MCC 校正仍无任何真信号**——负结论在**类型化口径下同样成立**，这比池化口径的证据更强。
- 之前发现的「gross_margin = 疫情 regime」「volume_ratio = 市值」「ttm_ocf = 行业 beta」等假象，全部是**池化框架下的正确纠错**，未失效；本文件新增的是「池化框架本身」这一层缺口。
- 后续 alpha 应聚焦：**另类数据 / 分析师预期(SUE) / 事件精确对齐 / 更细粒度类型化因子（银行不良率、保险 NBV、半导体资本开支等，需补数据源）**。
